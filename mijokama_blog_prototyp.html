GitHub Hosting Anleitung

  1. Erstelle auf GitHub ein neues Repository (z. B. mijokama-blog).
  2. Speichere diesen Code als index.html.
  3. Lade die Datei in dein Repository hoch.
  4. Gehe in die Repository-Einstellungen auf Pages.
  5. Wähle den Branch (z. B. main) und klicke auf Save. Deine Website ist online!
